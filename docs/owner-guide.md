# دليل راصد ٣ (للمالك ولأي مساعد ذكي بعد سنة)

## الفكرة في ثلاثة أسطر
- **المحرّك** يعمل على خوادم غيت هاب كل ٣ ساعات: يجلب صفحات الجهات، يقارنها بما رآه، ويرسل الجديد فقط للذكاء ليصنّفه، ثم ينبّه على تيليجرام وينشر `results.json`.
- **وسيط الجهاز** على كمبيوتر المالك: يجلب المواقع السعودية التي ترفض خوادم أمريكا، ويرفع نصّها. ويعمل حارساً مستقلاً ينبّه إذا توقّف المحرّك.
- **التطبيق** صفحة عامة تقرأ `results.json` وتحسب نسبة المناسبة في جهاز كل مستخدم.

## الخريطة
| المكان | ماذا فيه |
|---|---|
| `config/entities.yaml` | ملف الجهات: عدّله بحرية (النجوم، القنوات). الخطأ يُرفض برسالة عربية تسمّي السطر |
| `config/providers.yaml` | سلسلة نماذج الذكاء وحصصها اليومية |
| `rasid/` | قطع المحرّك، كل ملف عمل واحد، ولكل قطعة اختبار في `tests/` |
| `relay/home_agent.py` | وسيط الجهاز والحارس |
| `app/` | التطبيق |
| `design/` | نماذج التصميم |
| فرع `state` | ذاكرة المحرّك (`state.json`) ونسخة سابقة (`state.prev.json`) وقائمة المواقع المحجوبة |
| فرع `inbox` | ما جلبه وسيط الجهاز |
| فرع `site` | الصفحة العامة (تُبنى آلياً) |

## إذا حصل كذا، شوف هنا
- **ما وصلت رسالة الصباح:** افتح صفحة التشغيل في غيت هاب (تبويب Actions، سير `engine`). آخر جولة حمراء؟ افتحها واقرأ السطر الذي يبدأ بـ `[راصد]` أو أول سطر فيه `Traceback`.
- **جاءك «الحارس: المحرّك ما اشتغل من X ساعات»:** نفس الشي. غالباً غيت هاب أوقف الجدولة (يحدث بعد ٦٠ يوماً بلا نشاط) أو انتهت صلاحية سرّ. شغّل الجولة يدوياً من زر `Run workflow`.
- **«مصدر لا يُقرأ منذ ٣ أيام»:** افتح الرابط بنفسك. إذا تغيّر عنوانه، عدّله في `config/entities.yaml`.
- **المواقع السعودية كلها فاشلة:** وسيط الجهاز متوقف أو الكمبيوتر مطفي. سجله في `state/home_agent.log` على الجهاز. لإعادة تشغيله: زر «شغّل وسيط الجهاز» في مجلد مهام راصد.
- **«كل نماذج الذكاء غير متاحة»:** الحصص اليومية خلصت أو تغيّرت أسماء النماذج. شغّل `uv run python scripts/probe_llm.py` لاختبارها، وعدّل `config/providers.yaml`. لا تُدخل نموذجاً لم ينجح في كل الأمثلة الذهبية.
- **مفتاح ذكاء انتهى:** أنشئ مفتاحاً جديداً، ضعه في `secrets.local.env`، واضغط زر رفع الأسرار.

## قواعد لا تُكسر
1. لا يُعلَّم مصدر «مقروء» إلا بعد نجاح حقيقي.
2. الفشل لا يحذف شيئاً؛ يذهب لطابور إعادة ظاهر.
3. كل معلومة معها اقتباس حرفي من المصدر؛ الاقتباس المختلق يُسقط الحكم.
4. لا بيانات شخصية في أي ملف عام (حارس الخصوصية يمنع الالتزام والنشر).
5. التنبيه يُعتبر مُرسلاً بإيصال فقط.
