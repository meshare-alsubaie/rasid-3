# راصد ٣

محرّك مجّاني يرصد إعلانات التدريب التعاوني لجهات السعودية من قنواتها الرسمية، ويصنّفها بذكاء اصطناعي مجّاني مع دليل مقتبس لكل معلومة، ثم ينبّه المشتركين.

## البنية باختصار
- `rasid/` قطع المحرّك، كل قطعة عمل واحد ولها اختبارها في `tests/`.
- `config/entities.yaml` ملف الجهات (يُعدّل يدوياً).
- `docs/plans/` خطة البناء، و`docs/owner-guide.md` دليل الصيانة.
- يعمل في غيت هاب أكشنز على مدار اليوم (موعده كل ساعة، وغيت هاب يُسقط أغلب المواعيد فيشغّله جهاز المؤسس بعد ١٠٠ دقيقة بلا جولة)، والأسرار في خزنة المستودع فقط.

## التشغيل المحلي للاختبارات
```bash
uv sync
uv run pytest
```
